# Tag

輕量的標籤元件，用於分類、狀態標示或關鍵字呈現。

- 三種外觀（`variant`）：`contained`、`outline`、`text`
- 五種預設色系（`color`），也接受任意 CSS 色值
- 三種尺寸（`size`）：`sm`、`md`、`lg`
- 支援 `deletable` 模式，右側顯示 ✕，點擊觸發 `delete` event

## 使用方式

```vue
<!-- 基本 -->
<Tag color="primary">標籤</Tag>

<!-- 框線樣式 + 可刪除 -->
<Tag variant="outline" color="alert" :deletable="true" @delete="onDelete">
  待處理
</Tag>

<!-- 自定義色值 -->
<Tag color="#7c3aed">自定義</Tag>
```
