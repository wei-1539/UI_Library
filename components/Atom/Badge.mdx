# Badge

附加在目標元素角落的數字或圓點，通知使用者待處理的事項數量。

- 支援數字 `content`，超過 `max` 自動顯示 `+max`
- `size="dot"` 只顯示純圓點，不帶文字
- `content="0"` 預設隱藏，可用 `showZero` 強制顯示
- 四個角落皆可定位（`placement`）

## 使用方式

```vue
<!-- 包裹目標元素，信息會定位在邊界上 -->
<Badge content="5" color="alert">
  <YourComponent />
</Badge>
```
